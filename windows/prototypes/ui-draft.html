首页调整（本轮已改，看左侧）：
  • 内核按钮互斥：运行中=停止+重启；未运行=启动（切换自）
  • 头部状态长文本 → 彩色状态点（悬停看详情，绿/黄/灰）；文本全下沉底部状态栏。 备选 头部完全不放状态、只留按钮——Boss 定
  • 复制代理命令 = CMD / PowerShell / Bash 三按钮（与托盘右键二级一致；Bash 保留请 Boss 确认）
  • 订阅源卡、分组区均可折叠（点 ▲▼ 试试）；分组区补了「分组 N」标题
  • 左上角 App 图标 → 应用菜单：关于 / 检查更新 / 关闭窗口（关闭=收起到任务栏托盘常驻，非退出；真退出走托盘菜单）

交互语义：
· TUN 模式（二级）：「关闭 TUN」+ 四种 stack 单选（当前项打勾）；选 stack=开启并切换，走与主窗同链路（未提权弹 UAC 确认）；mips 不满足内核版本时置灰
· 内核操作组按状态动态：未运行=「启动内核」单项；运行中=「停止内核」+「重启内核」两项——与主窗互斥按钮同语义；远程目标下整组置灰
· 退出：真退出（关内核+清系统代理）；「关闭窗口」仅收起（应用菜单里）
